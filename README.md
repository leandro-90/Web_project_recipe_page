# 🍳 Projeto Web: Página de Receita

Um projeto focado no desenvolvimento de uma interface web para apresentação de receitas culinárias. Este repositório armazena a estrutura para uma página limpa, acessível e bem estruturada, focada em proporcionar uma ótima experiência de leitura e navegação.

## 🚀 Status do Projeto

Em desenvolvimento inicial. 

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://github.com/leandro-90/Web_project_recipe_page):** Utilizado para toda a estruturação semântica do conteúdo da receita (atualmente representando 100% da base de código).
- **CSS3:** Planejado para estilização responsiva, organização do layout e aplicação da metodologia BEM.

## 📁 Estrutura de Arquivos

A organização atual do repositório reflete a base do projeto:

- `ativos/ imagens/`: Diretório destinado às fotos da receita e demais recursos visuais.
- `projeto/`: Arquivos complementares e assets de planejamento do desenvolvimento.
- `index.html`: Arquivo principal contendo a marcação estrutural da página de receita.
- `.gitignore`: Configurações de arquivos e pastas ignorados no controle de versão.
